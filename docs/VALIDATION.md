## 可重复验证

在仓库根目录执行：

```powershell
python scripts/verify_migration.py
```

该脚本仅依赖 Python 标准库，检查迁移记录唯一性、路径范围、文件存在性、大小、SHA-256、Git blob SHA-1 与新增说明的本地链接。修改原文件后校验会报告差异；它是本次迁移的基线检查，不是应用运行测试。
